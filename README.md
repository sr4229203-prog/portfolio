## Deployment Instructions

### Deploy to GitHub Pages
```bash
npm install gh-pages --save-dev
npm run deploy
```

Your portfolio will be live at: `https://rssrndar-crypto.github.io/portfolio/`

### Run Locally
```bash
python3 -m http.server 8000
```

Visit: `http://localhost:8000`
